
# Theme: Teamwork Skills & Dispositions

- **Contribution**: An individual's input to team activities or outcomes. Code when assessing what each member contributes to the team's work.
- **Culture Fit**: Alignment with a team's or organisation's values, norms, or working culture. Code when assessment concerns how well someone fits into a particular team or workplace culture.
- **Technical Skills**: Technical knowledge or ability relevant to the task. Code when evaluating members' technical competence.
- **Learning Ability**: Capacity to acquire or apply new knowledge. Code when assessing learning, improvement, or uptake of feedback.
- **Problem Solving**: Ability to identify and resolve problems. Code when discussing how members approach or solve team challenges.
- **Assistance**: Support provided to teammates. Code when evaluating helping, sharing knowledge, or enabling others' work.
- **Coordination**: How team members organise and align their work. Code when discussing task allocation, timing, or managing dependencies.
- **Leadership**: Guidance or influence within the team. Code when assessing direction-setting, decision-making, or motivating others.
- **Negotiation**: Working through differences to reach agreement. Code when discussing compromise, priorities, or resolving competing views.
- **Social Skills**: Interpersonal behaviours that support collaboration. Code when assessing relationship-building or interaction with teammates.
- **Adaptability**: Response to changing needs or circumstances. Code when discussing adjustment to new tasks, plans, or team conditions.
- **Professionalism**: Conduct aligned with professional expectations. Code when discussing respectful, responsible, or workplace-appropriate behaviour.
- **Communication**: Exchange of information and ideas. Code when assessing clarity, timeliness, or effectiveness of team communication.
- **Curiosity**: Interest in exploring or understanding ideas. Code when discussing asking questions, investigating, or seeking knowledge.
- **Dealing with Slackers**: Managing members who contribute less than expected. Code when discussing low participation, accountability, or uneven effort.
- **Emotional Intelligence**: Recognising or managing emotions in oneself or others. Code when discussing empathy, emotional awareness, or regulation.
- **Giving & Receiving Feedback**: Providing or responding to feedback. Code when discussing feedback between teammates or from assessors.
- **Ownership**: Taking responsibility for work or outcomes. Code when discussing accountability beyond simply completing assigned tasks.
- **Reliability**: Consistency in fulfilling commitments. Code when discussing dependability, follow-through, or meeting expectations.
- **Initiative**: Acting proactively without being prompted. Code when discussing independently identifying or starting needed work.
- **Motivation**: Drive or willingness to engage in teamwork. Code when discussing effort, commitment, or reasons for participation.
- **Inclusion**: Ensuring team members can participate and are valued. Code when discussing equitable participation, belonging, or exclusion.

# Theme: Assessment Methods

- **Decision Logs**: Records of team decisions and reasoning. Code when logs or decision trails are used to assess teamwork.
- **Metrics**: Quantitative indicators of teamwork. Code when numerical measures, scores, or performance indicators are used.
- **Midterm**: Assessment conducted during a project or course. Code when a mid-project checkpoint is used to evaluate teamwork.
- **Monitoring**: Ongoing observation or tracking of team activity. Code when teamwork is assessed through continuous or repeated oversight.
- **Oral**: Spoken assessment or questioning. Code when interviews, presentations, or oral exams are used to evaluate teamwork.
- **Peer Review**: Assessment by team members. Code when team members assess one another's contributions or behaviours.
- **Reflection**: Learner or team review of their own process. Code when reflective accounts are used as assessment evidence.
- **Rubrics**: Assessment against defined criteria or levels. Code when a rubric or structured rating guide is used.
- **Self-Report**: Assessment based on individuals' own accounts. Code when surveys, statements, or self-ratings provide evidence.
- **Other**: An assessment method not captured by the listed codes. Code when a distinct method is named; specify it in notes.

# Theme: Misalignment (Industry–Academia)

- **General vs. Company-Specific Knowledge**: Difference between broad knowledge and organisation-specific knowledge. Code when expectations for general versus company-specific know-how differ.
- **Individualised vs. Standardised Assessment**: Difference between tailored and uniform assessment. Code when contexts favour individual-specific versus common assessment approaches.
- **Instructor Capacity & Expertise**: Constraints in educators' time, resources, or expertise. Code when these affect assessment design or delivery.
- **Learning Goals vs. Delivery**: Difference between intended learning and practical work demands. Code when assessment or teamwork goals conflict with what is delivered.
- **Legal & Regulatory Constraints**: Rules or obligations shaping assessment. Code when legal, privacy, or regulatory requirements are raised.
- **Practical Engineering Skills Gap**: Difference between academic preparation and workplace engineering needs. Code when practical skills expectations are seen as unmet.
- **Process vs. Outcome**: Emphasis on how work is done versus what it produces. Code when contexts prioritise teamwork process or final results differently.
- **Role Specialisation vs. Uniform Learning**: Difference between specialised workplace roles and broad educational expectations. Code when role-specific expertise conflicts with everyone learning the same skills.
- **Selection vs. Inclusion**: Tension between choosing high-performing members and ensuring participation. Code when selection or evaluation practices affect inclusion.
- **Structured vs. Ill-Defined Tasks**: Difference between clearly specified and ambiguous work. Code when task structure affects teamwork or assessment.
- **Team Formation & Composition**: How teams are assembled and who is included. Code when membership, size, or composition shapes assessment or teamwork.
- **Time Frame of Observation**: Difference in how long teamwork is observed. Code when assessment duration or timing creates a mismatch.
- **Tooling & Practices**: Differences in tools or working practices. Code when technology, workflows, or conventions affect assessment across contexts.

# Theme: Misalignment Criteria/Methods

- **Methods Do Not Withstand AI**: Assessment may be undermined by AI use. Code when a method's validity or integrity is questioned because AI can perform or distort it.
- **Methods Not Legally Defensible for Academia**: Assessment lacks a defensible basis under academic rules or law. Code when legality, fairness, or formal justification is questioned.
- **Methods Measure the Wrong Criterion**: Assessment captures something other than the intended skill. Code when a method is said to assess an irrelevant or unintended construct.
- **No Method to Measure Criterion**: No suitable assessment approach is available. Code when a criterion is recognised but cannot currently be assessed.
- **Not Enough Data to Measure**: Evidence is insufficient for a reliable judgement. Code when limited observations or records prevent assessment.
- **Measurement Unreliable (e.g., Self-Report)**: Assessment evidence is inconsistent or untrustworthy. Code when reliability concerns are raised, including self-report limitations.
- **Subjective Evaluator Judgement**: Assessment depends heavily on an evaluator's personal interpretation. Code when ratings are described as subjective or inconsistent across assessors.
