# Teamwork Assessment in Computer Science Education and Industry

## Overview
This repository contains:
1. The interview protocol for interviews with industry practitioners.
2. The panel protocol for panels with educators.
3. The codebook used for and created during qualitative analysis. 

## Methodology of creating the codebook
Initial codes were derived from the research question ("How do industry practitioners and educators differ in their expectations and assessment of CS graduates’ teamwork skills?") and related literature [1], [2]. 
We applied the same codebook to the panel and interview transcripts. 
Following coding, we grouped coded excerpts by theme and used a KJ diagram approach [3] to cluster the data into categories and identify underlying patterns and relationships. 
This process resulted in 52 categories across four themes. 
These four themes are reflected in the codebook, along with subcodes identified using KJ diagram analysis.
